## 3. البنية الحالية (Modular Monolith)

تطبيق Next.js 16 واحد، Prisma 5 / PostgreSQL، **قاعدة بيانات لكل عميل**، وعدة شركات نظامية داخل القاعدة.

الوحدات الجديدة في `src/modules/<domain>/` (واجهة عامة واحدة `index.ts`، والكاتب الوحيد `transitions.ts`):

| الوحدة | تملك |
|---|---|
| `platform` | الأحداث (outbox)، مفاتيح العمليات (عدم التكرار)، سجل التدقيق غير القابل للتعديل، الفترات النافذة، الثوابت والاختلافات، مشغّل المهام، **بوابة المال** |
| `iam` | سياقات المستخدم ونطاق الشركات، `authz.can`، عميل Prisma مقيّد بالشركة (يرفض العمل بلا سياق) |
| `lifecycle` | حالة التوظيف (السجل هو الحقيقة) وفتراتها، الانتقال الوحيد `transitionEmploymentState` |
| `org`، `people`، `calendar`، `rules` | التعيين، قفل الموظفين، أنماط العمل والعطل ورمضان، القيم القانونية بمصادرها |
| `payroll`، `finance`، `compensation`، `time`، `offboarding` | كتّاب المال كلٌّ في وحدته، عبر البوابة |

الكود القديم في `src/lib` و`src/app/api` يُنقل تدريجياً؛ **سقّاطة معمارية** (`src/test/architecture/baseline.json`) تمنع أي مخالفة جديدة وتسمح للقائمة بالانكماش فقط (من 709 مخالفة إلى 338 حتى الآن).

## 7. طريقة العمل المتبعة (يجب الحفاظ عليها)

- **قبل أي كود:** قراءة الدستور، والإجابة عن الأسئلة الستة.
- **القواعد الصلبة** (`CLAUDE.md`): لا كتابة مباشرة للمال أو الحالة أو الراتب؛ لا نسخة ثانية لمعلومة؛ لا أثر جانبي داخل معاملة؛ كل عملية جديدة بلا تكرار ولها اختبار استدعاء مزدوج؛ كل مسار معدّل له اختبار سماح ورفض وشركة أخرى بتسجيل دخول حقيقي.
- **الترحيلات:** نظام الحروف (`9x_…`)، لا `10+`، ولا تعديل لترحيل مطبَّق. **التالي الحر: `9zh`** (بعد P1-PAY-B).
- **الفحص قبل كل commit:**
  ```bash
  npm run typecheck && npm run lint && npx vitest run
  ```
  ثم على قاعدة PostgreSQL 16 مؤقتة (Docker): `prisma migrate deploy`، وفحص الانحراف `prisma migrate diff --exit-code`، وتشغيل كل اختبارات القاعدة بالأعلام `PLATFORM_IT EFF_IT SCOPE_IT ONBOARDING_IT INV_IT JOBS_IT LCY_IT CAL_IT RULE_IT PAY_IT` مع `UPLOAD_DIR`.
- **توجيه الوكلاء** (`.claude/agent-routing.md`): Opus للتصميم والمال والصلاحيات والنطاق والترحيلات التي تنقل بيانات؛ Sonnet للتنفيذ المحسوم والاختبارات؛ Haiku للبحث والصياغة. **حارس آلي** (`.claude/hooks/enforce-agent-routing.mjs`) يرفض أي وكيل عام بلا نموذج صريح. السجل الأساسي: 22 وكيلاً، 7.55 مليون وحدة، 100% Opus؛ أول نتائج بعد التوجيه: وكيل Sonnet بـ 76 ألفاً مقابل متوسط 343 ألفاً.
- **الحفظ:** commits محلية فقط حتى يقرر المالك الرفع؛ بأسطر هذا العمل فقط.
