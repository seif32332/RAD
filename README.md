## نبذة

**رديف** نظام موارد بشرية صُمم للسوق السعودي، للمنشآت ذات الهياكل المتعددة (شركات ← إدارات ← فروع ← أقسام). يجمع في مكان واحد ملفات الموظفين ووثائقهم، والحضور، والإجازات، والرواتب، والتسويات، والشؤون القانونية، والعلاقات الحكومية، واللوجستيات، بواجهة عربية كاملة.

لكل عميل نسخة مستقلة بقاعدة بيانات وملفات خاصة به، فلا تختلط بيانات منشأة بأخرى.

---

## الميزات

- **الكيانات والهيكل التنظيمي:** شركات متعددة ووثائقها، والهيكل من الشركة حتى القسم، وتراخيص الفروع وعقود الإيجار.
- **الموظفون:** ملف شامل بالوثائق والعقود، واستيراد جماعي من Excel، وتنبيهات بانتهاء الوثائق.
- **الحضور:** جداول العمل، وربط أجهزة البصمة، وطلبات التصحيح، وتسجيل حضور ذاتي من بوابة الموظف بالموقع الجغرافي والتحقق من الوجه.
- **الإجازات والتأشيرات:** مسار موافقات، وحساب الرصيد، والإجازات النظامية، وتأشيرات الخروج والعودة والخروج النهائي.
- **الرواتب والمالية:** مسير شهري بالبدلات والخصومات والسلف، والتأمينات الاجتماعية بنظاميها، والتسويات ونهاية الخدمة، وأوامر الدفع مع فصل صلاحيات الطلب والاعتماد والصرف.
- **الشؤون القانونية:** السندات لأمر، والعقود، والقضايا، والتحقيقات الإدارية.
- **التكامل مع منصة مقيم:** مطابقة المقيمين، وإصدار تأشيرات الخروج والعودة، وتجديد الإقامة، وتحديث الجواز، والخروج النهائي.
- **اللوجستيات والخدمات:** المركبات، وشرائح الاتصالات، والعدادات، والعهد والأصول.
- **البوابات:** بوابة للموظف والمدير والمالك، وسجل تدقيق لكل العمليات الحساسة.

---

## الأمان

- صلاحيات حسب الدور (11 دوراً) تُفرض على الخادم في كل طلب.
- جلسات موقّعة في cookie محمية، تُبطل عند تسجيل الخروج أو تغيير كلمة المرور.
- الوثائق الشخصية لا يطّلع عليها إلا المخوَّلون، وتُسجَّل كل قراءة لها.
- البيانات الحساسة مشفرة، والأسرار خارج الكود دائماً.

## التشغيل المحلي

المتطلبات: Node.js 22، وPostgreSQL 14 أو أحدث.

```bash
npm ci
cp .env.example .env          # ثم عدّل قيم البيئة
npx prisma migrate deploy
npm run db:seed
npm run admin:create -- admin@example.com
npm run dev
```
